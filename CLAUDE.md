# MetaFrame Studio — агрегатор AI-генерации

Next.js 16 на Vercel (проект `metaframe-ai`, команда doxa-tells, репозиторий `doxa-tells/metaframe_ai`).
Приложение живёт под префиксом `/studio`: metaframe.ltd/studio (см. `lib/base.ts`, `next.config.ts`).

## Как работать с владельцем
- Делать самому всё, что можно, не задавать лишних вопросов. В конце давать одну готовую команду пуша.
- Ключи и секреты никогда не печатать и не коммитить. Ключи лежат только в переменных окружения Vercel.
- Вопросы счёта и юрлица Kaspi не трогать.
- Отвечать по-русски, коротко, без воды.

## Провайдеры
- Google: Nano Banana 2.1, Gemini Omni (`lib/providers/google.ts`).
- BytePlus (Ark): Seedream 5.5 и 5.0, Seedance 2.5 напрямую (`lib/providers/byteplus.ts`, `arkAssets.ts`).
  База API: https://ark.ap-southeast.bytepluses.com/api/v3. Постоплата, библиотека ассетов: 3 создания в минуту, 50 ассетов.
- Higgsfield API: Soul, Kling 4.0, Genjutsu, Seedance-HF (`lib/providers/higgsfield.ts`).
- Хранилище: Cloudflare R2 через воркер (`cloudflare/`, `lib/storage.ts`). Деплой воркера: `cd cloudflare && npx wrangler deploy`.

## Где что лежит
- `app/api/generate` — запуск генерации; `app/api/jobs` — опрос и отмена задач; `app/api/upload` — загрузки.
- `lib/jobs.ts` — жизненный цикл задач, отправка провайдерам, возвраты кредитов, метки `pending-index/`.
- `lib/ledger.ts` — журнал кредитов (append-only, идемпотентные списания и возвраты).
- `lib/usage.ts` — счётчики лимитов; `lib/precheck.ts` — проверка рефов Seedance через ассеты BytePlus.
- `lib/errors.ts` — понятные пользователю тексты ошибок; `lib/models.ts` — каталог моделей.
- `components/Studio.tsx` — главный экран; `components/AdminPanel.tsx` — админка.
- `proxy.ts` — вход обязателен везде, кроме списка `PUBLIC` и исключений в `matcher`.
- `lib/session.ts` — сессии и подписанные токены; `lib/authflow.ts`, `lib/mail.ts`, `lib/captcha.ts` — Google, письма, капча; роуты в `app/api/auth/`.
- `lib/plans.ts` — лимиты по пакету (одновременные генерации, кредиты в сутки, частота).
- `public/presentation/` — статическая презентация, открыта без входа: /studio/presentation.

## Безопасность (не ломать)
- Выкладка: сначала пуш, потом `wrangler deploy`. Воркер без секрета отдаёт только `out/` и `uploads/`.
- Запрос генерации всегда проходит `normalizeRequest` до расчёта цены; при цене 0 запуск запрещён.
- Рефы пользователей — только `isOwnMediaUrl` (lib/storage.ts); скачивание в память — с потолком размера.
- Слоты (`reserveSlot`), списание и суточный лимит работают по схеме «записал → перепроверил → откатил своё».
- Очередь: задачи с `providerRequestId: wait:…` запускает `startQueued` под замком `locks/start/`.
- Карточка пользователя — только через `updateUser` (условная запись по метке версии).
- `STORAGE_SECRET` менять нельзя: от него зависят шифрование аккаунтов и (без `SESSION_SECRET`) подпись сессий.

## Известные особенности
- Seedance «правка видео»: при видео-рефе BytePlus требует `duration: -1` и `ratio: "adaptive"`; `lib/jobs.ts` повторяет запрос сам.
- Genjutsu принимает исходник не длиннее 30 с.
- Ошибка BytePlus с QPM/RPM — это лимит частоты, а не нехватка места в библиотеке ассетов.
- BytePlus иногда теряет задачу (404 при опросе) — задача закрывается ошибкой и кредиты возвращаются.
- В `lib/precheck.ts` повторное использование ассетов по отпечатку отключено, кэш в `precheck/seedance-v2/`.

## Открытые задачи
- Резервные копии R2 (аккаунты, журнал кредитов) — пока нет.
- Проверить в админке, что у пользователей разные IP: если один на всех, лимиты по адресу надо переводить на другой заголовок.
- Сбрасывать фильтр «Избранное» при запуске генерации (новые задачи не видны под фильтром).
- Предупреждение для Genjutsu, если видео длиннее 30 с.
- Плашка «вышла новая версия» для давно открытых вкладок.
- В презентации заявлены бренд-кит, языковые версии, запуск по расписанию, ElevenLabs и Suno — в коде их пока нет.
