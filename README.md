# AI Studio

Личный агрегатор генераций: Nano Banana 2.1 (Google), Seedream 5.5 / 5.0 и Seedance 2.5 (BytePlus напрямую), Higgsfield Soul 2 и Soul Cinema, Kling 4.0 (через Higgsfield).
Разделы: Фото (с историей), Видео, Ноды (React Flow) и боковой промпт-ассистент.

## Переменные окружения

| Переменная | Обязательна | Что это |
|---|---|---|
| `APP_PASSWORD` | да | пароль владельца: на странице входа оставить почту пустой и ввести его |
| `GEMINI_API_KEY` | для Nano Banana и чата | ключ Google AI Studio (с подключённой оплатой) |
| `ARK_API_KEY` | для Seedance и Seedream | ключ BytePlus ModelArk (console.byteplus.com/ark → API Key Management) |
| `HF_API_KEY` | для Soul 2, Soul Cinema, Kling | ключ Higgsfield API целиком (`id:secret`) из console.higgsfield.ai |
| `ANTHROPIC_API_KEY` | нет | если задан, чат работает на Claude |
| `STORAGE_URL` | да (на Vercel) | адрес воркера Cloudflare R2, например `https://metaframe-storage.<имя>.workers.dev` |
| `STORAGE_SECRET` | да (на Vercel) | общий секрет воркера (создаёт `cloudflare/setup.sh`) |
| `BLOB_READ_WRITE_TOKEN` | нет | запасной вариант: Vercel Blob вместо R2 |
| `NANO_BANANA_MODEL`, `GEMINI_CHAT_MODEL`, `ANTHROPIC_MODEL`, `ARK_MODEL_SEEDANCE_2_5`, `ARK_MODEL_SEEDREAM_5_0_PRO` и т.п. | нет | переопределить ID моделей |
| `ARK_BASE_URL` | нет | по умолчанию `https://ark.ap-southeast.bytepluses.com/api/v3` |
| `MOCK_PROVIDERS=1` | нет | тестовый режим без реальных генераций |
| `SESSION_SECRET` | желательно | ключ подписи сессий (64 случайных символа). Не задан — берётся производный от `STORAGE_SECRET`. Смена ключа разом закрывает все сессии |
| `APP_URL` | нет | публичный адрес сайта без `/studio` (по умолчанию `https://metaframe.ltd`): ссылки в письмах и адрес возврата от Google |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | для входа через Google | OAuth-клиент из Google Cloud Console. Адрес возврата: `https://metaframe.ltd/studio/api/auth/google/callback` |
| `RESEND_API_KEY`, `MAIL_FROM` | для писем | ключ Resend и адрес отправителя (по умолчанию `MetaFrame <no-reply@metaframe.ltd>`): подтверждение почты и сброс пароля |
| `TURNSTILE_SITE_KEY`, `TURNSTILE_SECRET_KEY` | для капчи | Cloudflare Turnstile: регистрация, сброс пароля и вход после 3 неудачных попыток |
| `CAP_HIGGSFIELD`, `CAP_BYTEPLUS`, `CAP_GOOGLE` | нет | сколько задач студия держит у провайдера одновременно (по умолчанию 8), остальные ждут в очереди студии |
| `REG_PER_IP_HOURLY`, `REG_TOTAL_HOURLY` | нет | регистраций в час с одного адреса (5) и всего (100) |
| `USER_AUTO_FREEZE` | нет | сколько отказов модерации за сутки замораживают пользователя (по умолчанию 10) |

## Локальный запуск

```
npm install
printf 'APP_PASSWORD=test\nMOCK_PROVIDERS=1\n' > .env.local
npm run dev
```

## Как устроено

- `lib/models.ts` — реестр моделей: режимы, параметры, входы, цены. Новая модель Higgsfield добавляется сюда без изменений в интерфейсе.
- `lib/providers/*` — адаптеры Higgsfield API и Gemini API.
- `lib/jobs.ts` — задачи: отправка, опрос статуса, копирование результата в своё хранилище (Higgsfield хранит файлы 7 дней).
- `lib/storage.ts` — Cloudflare R2 через воркер (`cloudflare/`), Vercel Blob или локальная папка `.data`.
- `cloudflare/` — воркер хранилища: отдаёт файлы публично (с Range для видео), пишет по секрету, браузер грузит референсы по подписанной ссылке.
- `components/nodes/*` — нодовый редактор и исполнение графа.

## Хранилище (Cloudflare R2)

```
bash cloudflare/setup.sh
```

Скрипт входит в Cloudflare, создаёт бакет `metaframe`, выкладывает воркер `metaframe-storage`, задаёт секрет, прописывает `STORAGE_URL` и `STORAGE_SECRET` в Vercel и пушит код. Значения также сохраняются в `.storage-env` (в git не попадает).

## Выкладка на Vercel

1. Установите Node.js 20+ (nodejs.org).
2. В папке проекта: `npm install`, затем `npx vercel` — войдите в аккаунт и подтвердите создание проекта `ai-studio`.
3. Хранилище: `bash cloudflare/setup.sh` (см. выше).
4. В Settings → Environment Variables добавьте `APP_PASSWORD`, `GEMINI_API_KEY`, `ARK_API_KEY`, `HF_API_KEY`.
5. `npx vercel --prod` — выкладка в продакшен.

## Пользователи и модерация

- Регистрация открыта: аккаунт открывается сам после подтверждения почты по ссылке из письма, а при входе через Google — сразу. Ручное подтверждение владельцем в разделе **Админ** остаётся для `MANUAL_APPROVAL=1` и когда письма не настроены.
- Аккаунт без кредитов на балансе ограничен: ассистент — `USER_CHAT_DAILY_FREE` (10) сообщений в сутки, загрузки — `USER_UPLOADS_DAILY_FREE` (20), проверка рефов Seedance и создание Soul ID закрыты.
- Данные пользователей разделены: генерации в `u/<uid>/jobs/`, чаты, ноды и избранное — в `u/<uid>/`, у каждого своя группа ассетов BytePlus.
- Меры: предупреждение (пользователь подтверждает прочтение), снятие генерации, заморозка на срок, блокировка (все сессии сразу закрываются), суточный лимит.
- Отказы модерации провайдеров учитываются автоматически; журнал всех действий — во вкладке «Журнал модерации».
- Аккаунты и журнал хранятся в R2 зашифрованными (ключ выводится из `STORAGE_SECRET`; не меняйте его, иначе записи станут нечитаемыми).

## Кредиты и оплата

- Пакеты и реквизиты — `lib/packages.ts` (Hobby 200 / 4 990 ₸, Plus 1 000 / 20 990 ₸, Pro 3 000 / 59 990 ₸; Kaspi и WhatsApp +7 705 992 64 40).
- Списание за генерацию — `lib/credits.ts`: Seedance 7/16 кредитов в секунду (720p/1080p), Nano Banana 2K — 2, остальное по себестоимости.
- Пользователь переводит на Kaspi и отправляет чек в WhatsApp со страницы «Кредиты»; в админке появляется заявка «Ждут кредиты», начисление — одной кнопкой.
- За неудачные, отменённые и заблокированные генерации кредиты возвращаются автоматически.

## Журнал кредитов, лимиты, фоновые задачи

- Баланс считается по журналу `u/<uid>/ledger/` (каждое движение — отдельный файл, сумма в имени). Списание и возврат по задаче имеют фиксированный ключ: двойной возврат невозможен, удаление генерации историю не стирает. Старый баланс из карточки пользователя переносится в журнал автоматически при первом обращении.
- Начисление в админке можно делать с номером чека Kaspi: один чек нельзя учесть дважды (индекс `receipts/`). История движений — в карточке пользователя.
- Суточный лимит — в кредитах, по пакету (см. ниже), владелец может задать свой каждому.
- Незавершённые задачи доводит сервер сам (метки `pending-index/`): возврат кредитов и сохранение результата не зависят от открытой вкладки.
- Длительность исходного видео для Genjutsu и правки видео Omni определяет сервер (по заголовку MP4).
- Лимиты пользователей (счётчики в хранилище, общие для всех копий функции): `USER_CHAT_DAILY` (150 сообщений ассистенту в сутки), `USER_SOUL_DAILY` (2 Soul ID в сутки), `USER_SOUL_TOTAL` (10 на аккаунт), `USER_UPLOADS_DAILY` (300 загрузок), `USER_PRECHECK_HOURLY` (40 проверок рефов в час), `MAX_UPLOAD_MB` (100). Неудачные входы: 30 с одного IP и 15 на одну почту за 15 минут.
- Проверка рефов Seedance: повторный файл узнаётся по содержимому и не отправляется в BytePlus заново; статусы берутся одним запросом ListAssets на всех; создание ассетов ограничено `ARK_ASSET_QPM` (по умолчанию 3 в минуту — тариф Entry), остальные встают в очередь с автоповтором.
- Ограничение размера загрузки в R2 включается после обновления воркера: `cd cloudflare && npx wrangler deploy`.

## Вход

- Почта и пароль, либо «Войти с Google». Через Google человек с новой почтой дозаполняет ФИО, телефон и согласия — и сразу попадает в студию.
- Подтверждение почты письмом открывает аккаунт (отметка видна в админке; подтверждение владельцем тоже засчитывает почту). «Забыли пароль» — ссылка на 1 час, срабатывает один раз, после смены пароля все прежние сессии закрываются.
- Кнопка Google, письма и капча появляются сами, когда заданы их ключи; без ключей студия работает как раньше.
- Сессии: cookie `mf_session` только под `/studio`, подписан отдельным секретом (не паролем владельца). Сессия владельца — 30 дней.
- Перебор: счётчики неудач в хранилище (30 с адреса и 15 на почту за 15 минут), после 3 неудач — капча.

## Лимиты и очередь

- Пакет пользователя (`lib/plans.ts`) — последний начисленный в админке, там же меняется вручную. Одновременно: Hobby 2 видео / 4 картинки, Plus 4 / 8, Pro 8 / 8. Кредитов в сутки: 200 / 1000 / 2000.
- Слот занимается до списания кредитов и проверяется после записи, поэтому параллельными запросами лимит не обойти (то же с суточным лимитом и балансом).
- Потолок провайдера (`CAP_*`): сверх него задача получает статус «В очереди» и стартует сама, когда освободится место; слоты раздаются по кругу между пользователями. Отмена из очереди возвращает кредиты.
- Частота: 10 запусков генерации, 30 загрузок и 10 сообщений ассистенту в минуту; запрос к ассистенту — до 200 тыс. символов.
- Метки `pending-index/<id>~<полоса>~<r|q>.json` — активные задачи; воркер хранилища раз в 2 минуты будит `/api/cron/sweep` (очередь и доводка задач работают и без открытых вкладок).

## Защита данных

- Воркер хранилища без секрета отдаёт только `out/` (результаты) и `uploads/` (рефы). Задачи, чаты, избранное, балансы, аккаунты и журналы читает только сервер.
- Рефы в генерациях, чате, проверке Seedance и Soul ID — только файлы из хранилища студии; сервер скачивает их с потолком размера.
- Запрос генерации приводится к описанию режима (`normalizeRequest`): параметры по умолчанию и типы проверяет сервер, при нулевой цене запуск запрещён.
- Карточка пользователя пишется условно (метка версии R2): параллельные правки не затирают друг друга.
- Порядок выкладки: сначала пуш (Vercel пересоберёт студию), потом `cd cloudflare && npx wrangler deploy`. Наоборот нельзя: прежняя версия студии читает служебные файлы без секрета.
